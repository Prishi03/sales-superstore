# 📊 Simple Sales Dashboard - Superstore Data

An interactive Power BI dashboard that visualizes sales performance by product category, region, and month using the Superstore dataset.

## 🎯 Objective

To create a clean, informative sales dashboard that highlights key metrics and trends using Power BI. This project demonstrates essential data analytics and dashboarding skills suitable for business stakeholders.

---

## 🛠 Tools Used

- **Power BI** – for dashboard design and interactive visuals

---

## 📁 Dataset

- **Source**: Superstore_Sales.csv  
- **Key Columns**:  
  `Order Date`, `Region`, `Category`, `Sub-Category`, `Sales`, `Profit`, `Ship Mode`

---

## 📌 Key Features

- 📅 Converted `Order Date` to **Month-Year** format using Power BI DAX
- 📈 **Line Chart**: Sales trend over months
- 📊 **Bar Chart**: Sales by Region
- 🍩 **Donut Chart**: Sales by Category
- 🧭 **Slicers**: Filter by Region, Category, and Segment
- 🎨 Custom color theme for a dark background

---

## 🔍 Key Insights

1. **📈 November** saw the highest monthly sales at **$270K**, marking a **50% increase** from the previous month.
2. **📱 Phones and Chairs** are the top-performing sub-categories, each generating over **$330K** in sales.
3. **🚚 Standard Class** shipping accounts for **59%** of total sales, making it the dominant shipping mode.
4. **🧭 The West region** leads in overall sales, while Central and East regions lag behind.
5. **🕒 Sales grew** steadily from 2014 to 2017, with a **52% jump in 2017** alone.
6. **🎯 Consumer segment** contributed the most to overall sales across all categories.
